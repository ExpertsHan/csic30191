和 Task 1 的 q_sample 是同一條公式 $x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$，只是資料變成 [B,C,H,W] 的影像，extract 會 reshape 成 [B,1,1,1] 做 broadcasting。函式同時回傳 eps，讓 loss 可以拿它當 ground truth。

TODO #2 Cosine beta schedule（Nichol & Dhariwal, 2021）

$$f(t)=\cos^2\!\Big(\frac{t/T+s}{1+s}\cdot\frac{\pi}{2}\Big),\quad \bar\alpha_t=\frac{f(t)}{f(0)},\quad \beta_t=\min\!\Big(1-\frac{\bar\alpha_t}{\bar\alpha_{t-1}},\ 0.999\Big),\quad s=0.008$$

s = 0.008
steps = torch.arange(num_train_timesteps + 1, dtype=torch.float64)       # t = 0..T
f = torch.cos(((steps / num_train_timesteps) + s) / (1 + s) * torch.pi / 2) ** 2
alphas_cumprod = f / f[0]                                                # ᾱ_0 = 1
betas = 1 - alphas_cumprod[1:] / alphas_cumprod[:-1]                     # T 個 β
betas = betas.clamp(max=0.999).float()
  • cosine schedule 是直接設計 $\bar\alpha_t$，再反推 $\beta_t$。算 $T$ 個 $\beta_t$ 需要 $T+1$ 個 $\bar\alpha$，所以 steps 取 0..T。
  • 除以 $f(0)$ 讓 $\bar\alpha_0=1$；小位移 $s$ 避免 $t$ 接近 0 時 $\beta_t$ 太小。
  • $t\to T$ 時 $\bar\alpha_t\to0$，比值會讓 $\beta_t\to1$，所以 clip 到 0.999。用 float64 計算，避免 $\bar\alpha$ 很小時相除產生數值誤差，最後再轉回 float32。

TODO #3 三種 predictor 的 reverse step

三種參數化最後都要算出 posterior $q(x_{t-1}|x_t,x_0)=\mathcal N(\tilde\mu_t,\tilde\beta_tI)$（DDPM Eq. 7）： $$\tilde\mu_t(x_t,x_0)=\frac{\sqrt{\bar\alpha_{t-1}}\beta_t}{1-\bar\alpha_t}x_0+\frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}x_t,\qquad \tilde\beta_t=\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\beta_t$$ 差別只在網路輸出的是哪一個量，所以我把共用的部分抽成 helper：

def _alpha_bar_prev(self, t, x_t):             # ᾱ_{t-1}，t = 0 時定義為 1
    prev = extract(self.alphas_cumprod, (t - 1).clamp(min=0), x_t)
    return torch.where((t == 0).view(prev.shape), torch.ones_like(prev), prev)

def _posterior_mean(self, x_t, t, x0_pred):    # μ̃_t
    return (ab_prev.sqrt() * beta_t / (1 - ab_t) * x0_pred
            + alpha_t.sqrt() * (1 - ab_prev) / (1 - ab_t) * x_t)

def _posterior_variance(self, x_t, t):         # β̃_t
    return (1 - ab_prev) / (1 - ab_t) * beta_t

def _add_posterior_noise(self, mean, var, t):  # t = 0 不加雜訊
    z = torch.randn_like(mean)
    nonzero_mask = (t != 0).float().view(-1, *([1] * (mean.dim() - 1)))
    return mean + nonzero_mask * var.sqrt() * z

def _posterior_sample(self, x_t, t, x0_pred):
    x0_pred = x0_pred.clamp(-1, 1)
    return self._add_posterior_noise(self._posterior_mean(x_t, t, x0_pred),
                                     self._posterior_variance(x_t, t), t)
  • noise predictor：先由 $x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$ 反解出 $\hat x_0=\dfrac{x_t-\sqrt{1-\bar\alpha_t}\,\hat\epsilon_\theta}{\sqrt{\bar\alpha_t}}$，再丟進 _posterior_sample。 
    x0_pred = (x_t - (1 - alpha_bar_t).sqrt() * eps_theta) / alpha_bar_t.sqrt()
sample_prev = self._posterior_sample(x_t, t, x0_pred)
  • x0 predictor：網路直接輸出 $\hat x_0$，直接呼叫 self._posterior_sample(x_t, t, x0_pred)。
  • mean predictor：網路直接輸出 $\mu_\theta\approx\tilde\mu_t$，只需要補上 $\tilde\beta_t$ 的雜訊：_add_posterior_noise(mean_theta, _posterior_variance(x_t, t), t)。
  • clamp(-1,1)：訓練影像被 normalize 到 $[-1,1]$，$\hat x_0$ 超出範圍一定是錯的，強制拉回可以避免誤差在 1000 步裡累積放大。
  • $\bar\alpha_{-1}=1$：在 $t=0$ 時 $\tilde\beta_0=0$、$\tilde\mu_0=\hat x_0$，最後一步直接輸出預測的乾淨影像。
  • step() 會先把 $t$ 統一轉成 device 上的 1-D tensor，再依 predictor 字串分派到上面三個函式。

觀察與討論：

  • linear：$\bar\alpha_t$ 下降得最快，$t=500$ 時已經只剩 $\bar\alpha\approx0.08$，所以 reverse 軌跡的前 6～7 格幾乎都是純雜訊，動物輪廓到最後 3 格才突然浮現。大部分的 timestep 花在「幾乎看不到訊號」的區間，真正決定影像結構和細節的步數比較少。
  • quad：$\beta_t$ 從 $\sqrt{\beta}$ 線性內插再平方，前段的 $\beta$ 比 linear 小很多，$\bar\alpha_t$ 衰減較慢（$\bar\alpha_{500}\approx0.33$）。軌跡約在中段（第 5 格）就出現輪廓，之後逐步補上細節。
  • cosine：$\bar\alpha_t$ 在中段近似線性下降、兩端平緩，雜訊強度在各 timestep 分佈最均勻。軌跡最早（第 3～4 格）出現輪廓，整個過程是由粗到細平滑演變。另外 $\bar\alpha_T\approx2\times10^{-9}$，$x_T$ 最接近純高斯，和取樣起點 $\mathcal N(0,I)$ 最一致。
  • 從生成結果看，三種 schedule 都能產生清楚的動物臉。FID 排名為 quad（0.83）< cosine（6.68）< linear（14.31），三者都低於 15，但 linear 明顯最差。我也在本機用同一個 AFHQ Inception 權重計算各組生成圖之間的 FID：quad 與 cosine 之間只有 3.7，但兩者和 linear 之間分別是 16.5 和 19.2，表示 quad／cosine 的輸出分佈很接近，linear 則偏離較多。原因應該就是上面提到的：linear 把太多步數浪費在高雜訊區，對細節的建模較不足。

觀察與討論：

  • noise predictor：target $\epsilon\sim\mathcal N(0,I)$，不論 $t$ 為何尺度都固定為單位變異數，對網路來說是一個條件良好的回歸問題。loss 很快降到 0.1 以下並穩定震盪，生成結果清楚、多樣（貓、狗、野生動物都有）。
  • x0 predictor：同樣能生成可辨識的動物臉，但整體紋理偏平滑、像塗抹過的水彩，毛髮等高頻細節較少，部分樣本的臉部結構也不自然（Fig. 7 x0 列第 3、4、7 張五官扭曲或殘缺）。原因是 $t$ 很大時要從幾乎純雜訊直接猜整張 $x_0$，MSE 的最佳解是「所有可能 $x_0$ 的條件平均」，所以預測偏模糊。loss 維持在 0.05～0.15 之間，比 noise 版本高、震盪也大。不過因為取樣時每一步只取 $\tilde\mu_t$ 的一小部分 $\hat x_0$，再加上 clamp(-1,1)，錯誤能逐步被修正，最終品質仍然不錯。
    值得注意的是，x0 的 FID（13.80）反而比 noise（14.31）略低。我的解讀是：評估用的 Inception 是在 AFHQ 上 fine-tune 過的（最後接 3 類 cat/dog/wild 分類頭），特徵偏重「物種、臉部整體結構與色彩」這類語意資訊，對毛髮等高頻紋理不敏感。x0 版本的模糊正好落在這個指標不太懲罰的地方，而它的語意分佈和真實資料相當接近（本機計算 x0 與 quad、cosine 生成圖之間的 FID 只有 9.3、4.0，比 noise 與它們之間的 16.5、19.2 還小）。因此在這個 FID 下兩者差距不大，但肉眼看 noise predictor 的細節明顯較好，FID 也不能完全代表影像的清晰度。
  • mean predictor：完全失敗，輸出是帶色塊的雜訊圖，軌跡也從頭到尾沒有出現影像結構。從 loss 曲線可以看出原因：
    1. $\tilde\mu_t=\frac{1}{\sqrt{\alpha_t}}x_t-\frac{\beta_t}{\sqrt{\alpha_t}\sqrt{1-\bar\alpha_t}}\epsilon$，而 $\beta_t\le0.02$，所以 target 幾乎就是 $x_t$ 本身，真正有用的去噪資訊只佔很小的尺度。loss 大多數時候接近 0（網路只要學會近似恆等映射就能拿到很低的 loss），梯度對「該往哪個方向去噪」幾乎沒有指導力。
    2. loss 曲線多次突然跳到約 1 再掉回來，代表訓練不穩定、會反覆發散。
    3. 取樣時每一步的微小誤差不會像 x0／noise 版本那樣經過 clamp 修正，1000 步累積之後完全偏離資料流形。
    這個結果和 DDPM 論文 Table 2 一致：作者指出用 unweighted MSE 直接預測 $\tilde\mu$ 會 training unstable，只有用真正的 variational bound（含 timestep 權重）才能訓練；這也是論文改用 $\epsilon$ 參數化的主要動機。
